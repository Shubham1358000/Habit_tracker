# 📅 Habit Tracker

![Habit tracking motivation](https://images.unsplash.com/photo-1517841905240-472988babdf9?auto=format&fit=crop&w=1200&q=80)

A simple habit tracker web app created with HTML, CSS, and JavaScript. The project helps users track daily habits and keep a small personal productivity routine.

## 🌟 Overview

This app is designed to demonstrate how a habit tracker can be built with a clean user interface and simple JavaScript logic. It focuses on tracking tasks and checking progress visually.

## ✨ Features

- ✅ Habit tracking interface
- 📝 Simple input and record flow
- 📈 Daily productivity style layout
- 🎨 Modern card-based design
- 📱 Responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📁 Project Structure

```text
Habit_tracker/
├── index.html

```

## ▶️ Run the Project

Open `index.html` in your browser, or run:

```bash
python -m http.server 8000
```

Then go to:

```text
http://localhost:8000
```
